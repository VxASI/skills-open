# Portfolio schema

Use the portfolio as an evidence index and adaptive capability profile, not a personality test.

## Main card

Keep approximately 6–8 dimensions relevant to the user's actual work and goals. Each row needs a score only when evidence warrants one.

| Capability | Score | Confidence | Trend | Evidence |
| --- | ---: | --- | --- | --- |
| Example capability | Not rated | — | — | 0 entries |

## Extended attributes

Keep relevant but lower-priority dimensions here. Promote, merge, rename, or remove dimensions as the evidence and user's context change.

## Evidence index

Link representative entries using relative paths, with a short explanation of why each is representative. Do not link private references from shareable sections.

## Required entry relationship

Every saved entry must have one matching private reference. The reference must include a sensitivity note and preserve enough context to evaluate the public entry without making the public entry verbose. Avoid exact quotations unless necessary.
