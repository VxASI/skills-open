# Agentic search and public-graph auditing

Read this reference for self-audits or when the goal involves agentic search, AI discoverability, machine-readable identity, or being found by intent rather than name.

## Audit the public graph

Simulate a stranger or agent discovering the target from scratch.

Evaluate:

- **Discoverability** — can they be found by name and by the work they want to be found for?
- **Identity coherence** — do profiles clearly represent the same person?
- **Current positioning** — is it obvious what they do now?
- **Evidence strength** — are important claims backed by visible work?
- **Entity linkage** — are aliases, brands, projects, domains, and profiles connected?
- **Freshness** — do prominent results represent current work?
- **Authority** — are there independent references, contributions, citations, or collaborations?
- **Narrative coherence** — does the footprint tell one understandable story?

Prioritize high-leverage gaps over generic SEO advice.

## Test agentic discoverability

Do not test only the person's name. Generate 3–5 realistic discovery intents from verified public work and stated goals.

Examples:

- `engineer building agentic systems`
- `open source AI evaluation tooling`
- `founder working on privacy-first personal finance`
- `researcher with browser-based document parsing experience`

Do not invent expertise they have not demonstrated.

For each intent, assess:

- **Retrievability** — is there public content that could surface for this intent?
- **Attribution** — can surfaced work be confidently connected back to the person?
- **Evidence quality** — does the result contain proof, or only self-description?
- **Entity consistency** — are names, aliases, domains, and handles connected clearly enough for an agent to merge them correctly?
- **Machine-readable signals** — where visible, do metadata, structured data, canonical links, bios, repository ownership, and cross-links reinforce the same identity?

## Gap classification

Separate three different failure modes:

- **Retrieval gap** — relevant work exists publicly but does not reliably surface for the intent.
- **Identity-linkage gap** — the work surfaces, but the agent cannot confidently connect it to the target.
- **Evidence gap** — the claim or positioning exists, but public proof is too weak to support confidence.

These gaps require different fixes. Do not collapse them into one generic discoverability score.

## Recommendations

Prefer the smallest changes that improve accurate discovery and attribution:

- canonical identity links;
- explicit authorship;
- consistent naming and handles;
- project attribution;
- descriptive page titles;
- structured metadata such as `Person` and `sameAs` where appropriate;
- evidence-rich project pages;
- cross-links between current profiles, projects, and domains.

Prefer semantic clarity and evidence over repetitive keywords.

Do not promise that a specific AI product will index or rank a page. Evaluate public signals that make correct retrieval and attribution more likely.

## Self-audit workflow

When the target is the user:

1. Search the real name without assuming aliases.
2. Record what appears first.
3. Search major known aliases or brands separately.
4. Determine whether public sources connect those identities.
5. Generate realistic intent searches from verified work.
6. Identify important work that is difficult to retrieve or attribute.
7. Classify retrieval, identity-linkage, and evidence gaps.
8. Recommend concrete linkage improvements.
9. Re-run periodically if the user wants to measure improvement.
